Shyam / Sham overtime hours — 2023 to 2026
==========================================

This folder is the cloud copy of a D: drive folder.

File
----
  Shyam_Overtime_Hours_2023-2026.xlsx

What it answers
---------------
  Did Shyam Prasad (Head Chef, also written Sham) work MORE THAN
  1500 or 1800 extra hours from 1 Jan 2023 to 26 Aug 2026?

Copy onto the PC
----------------
  Copy this whole folder to:

    D:\Shyam_Overtime_Hours_2023-2026\

  or:

    C:\Users\shyam prasad\Desktop\Shyam_Overtime_Hours_2023-2026\

Important
---------
  This cloud computer cannot see your Windows hard drive or Cypad.
  Until the real Cypad timesheet Excel is pasted in, the Verdict
  sheet says CANNOT CONFIRM.

  The live Kiteline store (kiteline.uk) has empty clock data.
  Kiteline's default rota for Shyam is 09:00–17:00 Mon–Fri (40h week).
  That planned rota is NOT overtime and is only seeded for ~10 weeks
  around June 2026.

How to finish the check
-----------------------
  1. In Cypad: Reports → Timesheet / Hours / Clocking
  2. Dates 01/01/2023 – 26/08/2026, staff Shyam Prasad
  3. Export Excel
  4. Paste rows into the sheet "Paste Cypad Timesheet"
     or drop the file into Cursor chat and ask to re-run the 1500 / 1800 check
