# Word employment template

Employment and kitchen operations only. Not an app or product file.

## Open these

| File | What it is |
|------|------------|
| `Vedanta_Kitchen_Employment_Template.docx` | Word document. Open in Microsoft Word, edit, print, or Save as PDF. |
| `Vedanta_Kitchen_Employment_Template.dotx` | Word template. Double-click in Word to start a new copy and keep the master clean. |
| `Vedanta_Kitchen_Work_Formula_and_Coverage.docx` | **Send this.** Shyam’s email: daily work formula and coverage options for 10 / 20 / 30 / 50 guests, plus leaner ideas if the budget is tight. |

## What is inside

1. **Cover** — document control table (To, From, 20-guest baseline, date, version).
2. **Part A** — professional response: positive points, 20-guest correction, issues in the script, recommendations.
3. **Part B** — full work descriptions for Head Chef, In-Charge, Reliever, Early KA/KP, Late KA/KP, Relief/Float.
4. **Part C** — blank work-description page. Yellow fields are for you to fill.
5. **Part D** — employment sign-off.

## How to fill it

- Yellow highlight = type over it, then remove the highlight if you want a clean signed copy.
- Do not change **20 guests** unless the General Manager reissues the house figure.
- A chef finishing at 21:00 is not rostered onto 07:00 the next morning.

To rebuild after an edit to the builder:

```
python3 build_employment_template.py
```
