# The Vedanta — Kitchen Employment Pack

This folder is **employment and kitchen operations only**.

It is a standalone work pack for The Vedanta hospitality team. It is not software, not a product, and not linked to any app, website, or other project.

## Documents

| File | Use |
|------|-----|
| `01-Professional-Response-to-Kitchen-Proposal.md` | Formal response to the Kitchen Operating Proposal. Starts with what is right, corrects the guest baseline to **20 guests**, then sets out the issues in the script. |
| `02-Full-Work-Descriptions-20-Guests.md` | Full employment work descriptions for Head Chef, In-Charge, Reliever Chef and KA/KP posts at the **20-guest** baseline. |
| `print/Kitchen-Employment-Response.html` | Printable meeting pack. Open in a browser and use Print / Save as PDF. |
| `word/Vedanta_Kitchen_Employment_Template.docx` | **Word file to open, edit and print.** Cover, filled response, full work descriptions, blank job-description page (yellow fields) and sign-off. |
| `word/Vedanta_Kitchen_Employment_Template.dotx` | Same file saved as a true Word template. In Word: File > New from template, or double-click to start a new document. |
| `03-Kitchen-Work-Formula-and-Coverage-Email.md` | Shyam’s professional email: 35 years’ experience, step-by-step daily formula, and coverage options for **10 / 20 / 30 / 50** guests — including a leaner idea if the budget is tight. |
| `print/Kitchen-Work-Formula.html` | Printable version of that email. |
| `word/Vedanta_Kitchen_Work_Formula_and_Coverage.docx` | Word file of the email and formula — send or print this. |

## Working baseline

The draft proposal was written for **30–35 guests**.  
The correct working figure for this pilot is **20 guests**.

## How to use

1. For Word / HR / printing: open `word/Vedanta_Kitchen_Employment_Template.docx`.
2. Overtype yellow fields in Part C for a new post. Keep **20 guests** unless the GM reissues the house figure.
3. File > Save As > Word Template (*.dotx) if you want a clean master. A `.dotx` copy is already in the same folder.
4. Read the professional response first if you want the markdown version.
5. Issue the work descriptions and keep a signed Part D.

**Kitchen owns the food and the technical kitchen standard. Restaurant owns guest-facing dining and refreshment. This pack does not change that principle.**
