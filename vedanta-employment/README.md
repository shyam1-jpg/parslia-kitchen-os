# The Vedanta — Kitchen Employment Pack

This folder is **employment and kitchen operations only**.

It is a standalone work pack for The Vedanta hospitality team. It is not software, not a product, and not linked to any app, website, or other project.

## Documents

| File | Use |
|------|-----|
| `01-Professional-Response-to-Kitchen-Proposal.md` | Formal response to the Kitchen Operating Proposal. Starts with what is right, corrects the guest baseline to **20 guests**, then sets out the issues in the script. |
| `02-Full-Work-Descriptions-20-Guests.md` | Full employment work descriptions for Head Chef, In-Charge, Reliever Chef and KA/KP posts at the **20-guest** baseline. |
| `print/Kitchen-Employment-Response.html` | Printable meeting pack. Open in a browser and use Print / Save as PDF. |

## Working baseline

The draft proposal was written for **30–35 guests**.  
The correct working figure for this pilot is **20 guests**.

## How to use

1. Read the professional response first.
2. Use the work descriptions for role clarity, recruitment, rota planning and review.
3. Print the HTML pack for the GM / Duty Manager meeting.

**Kitchen owns the food and the technical kitchen standard. Restaurant owns guest-facing dining and refreshment. This pack does not change that principle.**
