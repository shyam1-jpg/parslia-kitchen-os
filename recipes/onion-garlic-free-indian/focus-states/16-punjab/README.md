# Punjab

**Kitchen:** Punjabi langar and home vegetarian  
**Diet:** vegetarian · no onion · no garlic · no aluminium cookware

Sarson saag, langar dal, makki roti, kadhi, pinni. Gurdwara cooking is onion-garlic free.
