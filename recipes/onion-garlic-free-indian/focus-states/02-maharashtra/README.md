# Maharashtra

**Kitchen:** Maharashtrian vegetarian and vrat cooking  
**Diet:** vegetarian · no onion · no garlic · no aluminium cookware

Pithla, varan, modak, koshimbir. Kokum and hing replace alliums.

Open first: [`index.html`](index.html) (recipe cards) or [`excel/maharashtra-recipes.xlsx`](excel/maharashtra-recipes.xlsx) (one sheet = one card).
