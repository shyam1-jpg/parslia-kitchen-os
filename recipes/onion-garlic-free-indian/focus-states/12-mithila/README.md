# Mithila

**Kitchen:** Maithil vegetarian (Bihar–Nepal border culture)  
**Diet:** vegetarian · no onion · no garlic · no aluminium cookware

Makhana, sattu, pua, dahi-chura, Maithil kadhi. A distinct kitchen from Magadh Bihar.
