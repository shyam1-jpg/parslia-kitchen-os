# Andhra Pradesh

**Kitchen:** Andhra vegetarian / temple pappu  
**Diet:** vegetarian · no onion · no garlic · no aluminium cookware

Gongura, pulihora, pesarattu, pachadi. Tamarind and chilli, not alliums.
