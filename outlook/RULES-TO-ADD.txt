Outlook rules to add (only if the one-click script cannot run)
============================================================

Best path: double-click FILE-ALL-EMAIL-FOLDERS.bat and sign in.
That files ALL company mail in your Hotmail (outlook.live.com).

Manual path: https://outlook.live.com/mail/ → Settings → Mail → Rules

Create a folder named Companies under Inbox, then one folder per company.
Outlook on the web allows about 64 rules, so add the companies you see most.

  Move to folder: Inbox / Companies / GitHub
  Stop processing more rules: Yes
