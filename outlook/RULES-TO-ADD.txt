Outlook rules to add (if the double-click script cannot run)
============================================================

Open Outlook → Home → Rules → Manage Rules & Alerts → New Rule
Or on the web: https://outlook.live.com/mail/ → Settings → Mail → Rules

Create a folder named Companies under Inbox, then one folder per company.

Rule: File → GitHub
  If sender address includes: github.com OR githubapp.com OR githubstatus.com OR githubcopilot.com
  Move to folder: Inbox / Companies / GitHub
  Stop processing more rules: Yes
