Add Kiteline to ChatGPT

Kiteline is a multipurpose hospitality platform. ChatGPT connects to your company only — recipes, menus, stock, temperatures, allergens, rotas and reports.

GPT logo (fixes empty search icon)

ChatGPT does not pick this up automatically. Upload it in the GPT editor so search and the GPT list show the Kiteline mark.

  1. Open your GPT: chatgpt.com/gpts/editor
  2. On Configure, click the circular profile / logo area
  3. Upload chatgpt-gpt-logo.png (512×512)
  4. Click Update / Save

If chat says “Something went wrong”

  1. Confirm health is green: /api/ai/health must show ok: true.
  2. In Kiteline → Settings → Connect ChatGPT, create a fresh kl_ai_… token while logged in as Admin.
  3. In the GPT editor → Actions, re-import schema:
    https://kiteline.uk/api/ai/openapi.json
  4. Authentication: API Key → Bearer / custom header with your token (not your Kiteline password).
  5. Privacy policy URL (Actions): https://kiteline.uk/privacy.html
  6. For ChatGPT Apps / MCP: URL https://kiteline.uk/mcp (no trailing slash). CORS must allow chatgpt.com — fixed in connector 1.2.2+.

What ChatGPT can do

  • Search recipes, products and dishes
  • Create and manage menus
  • Search stock and suppliers
  • Generate shopping and ordering lists
  • Read and add temperature records
  • Generate allergen and nutrition reports
  • Search staff rotas and operational records
  • Produce business, cost and compliance reports
