Your company email folders

They are not on the Windows desktop. They live inside Outlook, on the left side.

If you only see one email filling the whole page, the folder list is hidden. That is why you cannot see GitHub, Cursor, Cloud, Apple, or Google yet.

1. Show the folder list in Outlook

  1. Open Outlook on this computer.
  2. Click View at the top.
  3. Click Folder Pane → Normal.
    New Outlook: click the folder icon on the far left, then look for Inbox.
  4. You should now see Inbox on the left — not only one email.

2. Create the first folder so you can see it

  1. On the left, right-click Inbox.
  2. Click New Folder (or Create new folder).
  3. Type GitHub and press Enter.
  4. Repeat for Cursor, Cloud, Apple, Google.

Those names now show under Inbox. That is the “neat” list.

3. Auto-drop new mail into those folders

Desktop Outlook (classic):

  1. Keep Outlook open.
  2. Double-click SETUP-OUTLOOK-FOLDERS.bat (same folder as this page, or inside the outlook folder).
  3. Press Y. It creates the rest of the folders, moves old company mail, and adds rules for new mail.

Or do it on the web (same Hotmail account):

Open Outlook on the web

  1. Sign in.
  2. Left list → right-click Inbox → Create new folder → name it GitHub.
  3. Repeat for Cursor, Cloud, Apple, Google.
  4. Settings (gear) → Mail → Rules → Add new rule.
  5. Example: name GitHub, condition “sender includes github.com”, action “Move to GitHub”.
