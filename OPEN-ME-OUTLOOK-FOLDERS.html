File every company into its own Outlook folder

They are not on the Windows desktop. They live inside Outlook, on the left: numbered company folders at the top, then Companies, then People.

Last time this was only a picture in GitHub. Your real Hotmail (shyam_1@hotmail.co.uk) was not organised. Double-click FILE-ALL-EMAIL-FOLDERS.bat on this PC to file the live mailbox.
That one click signs you into Outlook on the web, creates a folder for each company (GitHub, Cursor, Apple, Google, Brakes, Bidfood, HMRC, and every other firm in the mailbox) and a folder for each person, moves the old mail, and adds rules so new company mail drops in by itself.

1. File the live mailbox (do this)

  1. On this Windows PC, double-click FILE-ALL-EMAIL-FOLDERS.bat (same folder as this page, or inside Desktop → Outlook-Company-Folders).
  2. A code appears. Open https://microsoft.com/devicelogin and enter the code.
  3. Sign in as shyam_1@hotmail.co.uk and allow mail access.
  4. Back in the black window, press Y.
  5. Wait until it says Done (large inboxes take a few minutes).

2. See the folders in Outlook

  1. Open outlook.live.com/mail and refresh.
  2. Look at the left list — not the Windows desktop.
  3. If one email fills the page: View → Folder Pane → Normal
    On the web, click the folder icon on the far left.
  4. Open Inbox. Apple, Google, GitHub and Cursor are numbered at the top. Other firms are under Companies. Friends are under People.

If the black window cannot sign in

  1. Open classic desktop Outlook (turn New Outlook off) and double-click SETUP-OUTLOOK-FOLDERS.bat.
  2. Or add folders by hand on the web: right-click Inbox → Create new folder → Companies, then one folder per company. Rules are listed in outlook/RULES-TO-ADD.txt.
