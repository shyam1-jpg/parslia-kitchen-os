    Auto setup — already on

    This page picks a new idea every day from the tip bank (no login needed). For AI-written fresh tips that update content/today.json each morning, turn on the Cursor Automation using the prompt in the repo.

    1. Open cursor.com/automations
    2. Create a Scheduled automation (daily cron, e.g. 0 7 * * *)
    3. Point the automation at the Pure Prasad Kitchen files only (`pure-prasad-kitchen/`)
    4. Paste the prompt from .cursor/automations/pure-prasad-daily.md
    5. Save & activate — each run writes a new tip and can open a PR
