# Fix messy Desktop — START HERE

Your Desktop is messy. Fix it in **2 clicks**.

---

## Do this on your Windows PC

### Step 1 — Get the tidy script

1. Open folder:  
   `C:\Users\shyam prasad\Desktop\parslia-kitchen-os\`  
   (or wherever you keep this GitHub repo)
2. Find the file: **`TIDY-DESKTOP.bat`**
3. **Copy** it to your Desktop

### Step 2 — Run it

1. Double-click **`TIDY-DESKTOP.bat`** on the Desktop  
2. Press any key when it asks  
3. Wait until it says **DONE**

Nothing is deleted — files are only **moved**.

---

## After it runs, Desktop looks like this

```
01-Parslia              ← Parslia code
02-Libraix              ← Libraix notes
03-Kiteline             ← Kiteline (separate)
04-Accounts-Passwords   ← logins / guides
05-Media                ← pictures / videos
06-Archive              ← everything else (safe)
```

Loose pictures, videos, PDFs, zips go into **05-Media** or **06-Archive**.

---

## If something is in the wrong place

1. Open `06-Archive\other-files`
2. Drag the file into the correct numbered folder
